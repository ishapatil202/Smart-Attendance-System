# Sample people

Every image in this folder is enrolled at startup as a sample person, so the
live demo is never empty. The file name becomes the person's name
(`Eileen_Collins.jpg` → "Eileen Collins"). Sample people are never auto-cleared.

| File | Source | License |
|---|---|---|
| `Eileen_Collins.jpg` | NASA portrait of astronaut Eileen Collins, as distributed in scikit-image (`skimage.data.astronaut`) | Public domain (NASA) |

Only add photos you have the right to use: public-domain portraits, or
people who have agreed to be in the demo.
